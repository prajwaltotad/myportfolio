## Overview

This portfolio is designed as a personal landing page for a Computer Science student and aspiring software developer. It highlights:

- academic background and current focus areas
- technical skills and tools
- major projects with details
- learning journey and growth areas
- profile links and contact section
- a sleek terminal-inspired UI with responsive design

## ✨ Features

- Responsive single-page layout
- Terminal-inspired aesthetic and developer branding
- Smooth scroll navigation and section-based structure
- Project cards with expandable detail modal
- Command palette-style quick navigation
- Contact form integration with FormSubmit
- Fully built with React + TypeScript + Vite

## 🛠 Tech Stack

- React 19
- TypeScript
- Vite
- CSS for styling and layout
- Oxlint for linting

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

- Node.js (v18 or newer recommended)
- npm or yarn

### Install dependencies

```bash
npm install
```

### Run locally

```bash
npm run dev
```

Then open the local URL shown in the terminal, usually:

```bash
http://localhost:5173/
```

### Build for production

```bash
npm run build
```

### Preview production build

```bash
npm run preview
```

## 📜 Available Scripts

```bash
npm run dev      # Start the Vite dev server
npm run build    # Type-check and build the production bundle
npm run lint     # Run lint checks with Oxlint
npm run preview  # Preview the production build locally
```
